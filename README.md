# ✦ AUROLYNE

> **A personal digital world for thoughts, dreams, ideas, and companions.**

AUROLYNE is a personal web application that combines **journaling, dream documentation, ideas, projects, digital companions, and AI interaction** in a magical and immersive environment.

## 🌙 Features

* 📖 Personal journal
* 🌙 Dream journal
* 💡 Ideas & projects
* 🐾 Digital companions
* 🤖 AI interaction
* 🎨 Pixel-art inspired world

## 🛠️ Technologies

* Node.js
* SQL
* Git & GitHub
